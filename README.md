# estimating_value_T

Проект для оценки стоимости квартиры в г. Рязань: генерация синтетического датасета и веб-приложение на Streamlit для предсказания цены.

## Что внутри

- `dataset.py` — генерация датасета недвижимости и базовый EDA.
- `web/app_streamlit_v3.py` — интерфейс Streamlit для расчёта стоимости квартиры.
- `web/model.pkl` — обученная модель, которую использует приложение.
- `requirements.txt` — зависимости проекта.

## Функциональность

- Генерация синтетических объявлений по районам/микрорайонам Рязани.
- Учёт площади, комнат, этажа, типа дома, года постройки, ремонта и дополнительных опций.
- Сохранение датасета в CSV и графиков EDA в PNG.
- Оценка стоимости квартиры через форму в Streamlit.

## Требования

- Python 3.10+
- pip

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

### 1) Сгенерировать датасет и графики

```bash
python dataset.py
```

После выполнения будут созданы:

- `ryazan_real_estate.csv`
- `eda_ryazan.png`

### 2) Запустить веб-приложение

```bash
cd web
streamlit run app_streamlit_v3.py
```

## Использование приложения

1. Выберите район и микрорайон.
2. Укажите параметры квартиры (площадь, комнаты, этаж и т.д.).
3. Нажмите **«Рассчитать стоимость»**.
4. Получите прогноз цены в рублях и цену за м².
